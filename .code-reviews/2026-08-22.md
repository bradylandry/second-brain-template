## Medium

### `--author` filter in `collect_git_activity` is never shell-expanded

- **File**: `scripts/narrative_generator.py:62`
- **Issue**: The string `"--author=$(git config user.email)"` is passed as a literal element in a subprocess argument list (`shell=False`). The `$()` substitution is not expanded by the shell — git receives the literal string `$(git config user.email)` as the author pattern. This matches no real author, so git returns all commits (or none if git treats it as a regex with no matches), not just the user's commits. The bug is silent — the function never errors, it just collects wrong data.
- **Fix**: Resolve the email before building the argument list:
  ```python
  author_result = subprocess.run(
      ["git", "config", "user.email"],
      capture_output=True, text=True, check=False, timeout=5,
  )
  author_email = author_result.stdout.strip()
  args = ["git", "-C", str(repo), "log",
          f"--since={day} 00:00", f"--until={day} 23:59",
          "--pretty=format:%s"]
  if author_email:
      args.append(f"--author={author_email}")
  ```

### Default `NARRATIVE_MODEL` references a stale model ID

- **File**: `scripts/narrative_generator.py:124`
- **Issue**: The fallback model `"claude-sonnet-4-5"` is outdated. The current recommended Claude Sonnet model is `claude-sonnet-4-6`. Users who rely on the default without setting `NARRATIVE_MODEL` will send requests to an older model.

  ```python
  model=os.environ.get("NARRATIVE_MODEL", "claude-sonnet-4-6"),
  ```

### `setup.sh` glob for skills `.md` files could fail if directory is empty

- **File**: `setup.sh:65`
- **Issue**: `cp "$SCRIPT_DIR/integrations/claude-code/skills/"*.md "$DEST/.claude/skills/"` under `set -euo pipefail` will fail if the glob matches nothing (the literal `*.md` string is passed to `cp`, which errors). Currently the skills directory is non-empty so this doesn't fire, but a future contributor adding a new integration branch without populating skills would hit a silent breakage.
- **Fix**: Add a no-op fallback:
  ```bash
  cp "$SCRIPT_DIR/integrations/claude-code/skills/"*.md "$DEST/.claude/skills/" 2>/dev/null || true
  ```
