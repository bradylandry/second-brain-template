## Medium

### `collect_git_activity`: `--author` filter is a no-op — all repo commits are included
- **File**: `scripts/narrative_generator.py:63`
- **Issue**: `--author=$(git config user.email)` is passed as a single string element in the subprocess list. Because `shell=False` (the default), the shell never evaluates the `$()` substitution — git receives the literal string `$(git config user.email)` as a regex. In practice this regex matches nothing or matches very strangely, so the time-range filter is applied but author filtering is not. The journal context includes every commit to every scanned repo on that day, not just the user's own commits. In shared or multi-contributor repos this inflates context with other people's work and can mislead the LLM narration.
- **Fix**: Resolve the email before constructing the command:
  ```python
  import subprocess as _sp
  user_email = _sp.run(
      ["git", "config", "user.email"], capture_output=True, text=True, check=False
  ).stdout.strip()
  # then pass f"--author={user_email}" in the log command
  ```
  If `user_email` is empty, omit the `--author` flag and log a warning.

### `setup.sh`: glob expansion fails under `set -euo pipefail` if skills directory is empty
- **File**: `setup.sh:65`
- **Issue**: `cp "$SCRIPT_DIR/integrations/claude-code/skills/"*.md "$DEST/.claude/skills/"` has no `|| true` guard. If no `.md` files exist in the skills directory, the glob expands to a literal `*.md` filename, `cp` fails with "No such file or directory", and `set -e` aborts the script mid-setup, leaving the destination directory partially populated.
- **Fix**: Add a guard: `cp ... 2>/dev/null || true`, or check `shopt -s nullglob` beforehand.

### `new-project.sh`: temp file not cleaned up if `mv` fails
- **File**: `vault/research-skill-graph/new-project.sh:148`
- **Issue**: `awk ... > "$ROOT_INDEX.tmp" && mv "$ROOT_INDEX.tmp" "$ROOT_INDEX"` — if `mv` fails (e.g., permissions or disk full), `$ROOT_INDEX.tmp` is left on disk next to the index file, which could confuse tools that glob for `.md` files.
- **Fix**: Use a trap to clean up the temp file on exit:
  ```bash
  trap 'rm -f "$ROOT_INDEX.tmp"' EXIT
  ```
  or inline: `awk ... > "$ROOT_INDEX.tmp" && mv "$ROOT_INDEX.tmp" "$ROOT_INDEX" || rm -f "$ROOT_INDEX.tmp"`.
